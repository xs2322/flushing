Keeping the data current

The map is one file and works offline, so each dataset is a copy from the date shown. Only the project team updates the data, by rebuilding the whole file from the publishers' own copies with the same rules; the map cannot load a list or a file from anyone else, so a copy of it can't be quietly changed to look official. "Check for newer data" asks each publisher when it last changed its dataset.
