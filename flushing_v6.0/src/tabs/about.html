About this sandbox

Where the City's report fits

The City's first Local Law 58 report (October 2026) calls its own analysis of underserved areas preliminary, and plans a more detailed method by 2030 (p. 11). This sandbox is one way to build that method, in the open, using the City's own restroom list.

On the same list it comes within a few points of the City's published coverage figures; the side-by-side is at the end of the Numbers page. Then it goes further: block by block, it shows why a place needs a restroom, where one is allowed to stand, and where the next ten should go.

What it does

It asks three questions about every block in the city: where is a restroom needed, where could one go, and where should the next one go? Each block gets a need tier from 1 (lowest) to 5 (highest).

Why now

Local Law 58 of 2025 calls for a citywide plan for public restrooms, with about 1,145 more needed by 2035. The law names what should guide siting, but not how to weigh it.

Why it's adjustable

Every setting can be changed and the map updates right away, so an agency can test its own assumptions. It ranks candidate sites; it does not choose them.

Before you use a result: tiers are estimates made from public data. Every site still needs a visit on the ground and agency approval.

How a block gets its tier, 1 to 5

  1. Is a restroom nearby?Within a 5-minute walk of an open restroom, a block is served and gets no tier. From 5 to 10 minutes it is partly served, and its tier is lowered by one. Beyond 10 minutes it is a gap.
  2. Five reasons, each rated 1 to 5.Each reason is measured with public data and turned into a rating from 1 to 5 using fixed cut-offs, the same in every district (table below).
  3. The strongest reason wins.The block takes its highest rating. Nothing is added up or weighted, so one strong reason is enough, the way DOT's Pedestrian Demand Map lets one busy street set a corridor's class.

How the cut-offs are set

A block's tier comes from its strongest reason, so a reason that reaches 5 easily would end up setting most tiers. To hold every reason to the same bar, the default cut-offs are calibrated to DOT's Pedestrian Demand Map: each resident reason reaches each tier about as often as a city block sits on the matching DOT street class. Tier 5 is about as rare as a Global street (2 in 100 blocks), tier 4 as rare as a Regional street, and so on.

The match is close, not exact. Resident shares are rounded to whole percentages and every block in a census tract has the same share, so vulnerable residents reach tier 3 a little more often than DOT's Neighborhood streets occur. And 65 in 100 blocks have no 311 complaint, so that reason can only be matched at tiers 4 and 5.

An earlier version used round numbers (35% vulnerable residents, 30% poverty, 5 complaints a year for tier 5). On those, one reason set most tier-5 blocks, so they were replaced. You can still choose Round numbers under Settings › Tier thresholds to compare.

Try it in a minute

  1. Start with Sites. The map opens on it: where a restroom is needed and where one can stand. The district's top 10 next sites are numbered on the map.
  2. Click a block. See its tier, the reason behind it, and the math.
  3. Press FLUSH! The map places restrooms one at a time on the neediest blocks where a unit is allowed, treating each as open before the next.
  4. Build the case. Each lens answers one agency's question: zoning, flood risk, cleaning routes, who represents an area. Each opens with the question it answers.
  5. Tell us what's missing. Know a public restroom the map doesn't? Report it.

Each letter is one thing the map weighs, and each keeps its colour across the tool. The name also points to Flushing, Queens, at the end of the 7 train. The map covers all five boroughs.

Help make the map better

The map only knows the restrooms on public lists. If you know a public restroom that's missing, closed, or listed wrong, send a report. Each report is checked by a person before anything on the map changes, and this page stores nothing you type.

Related work

Bathroom Deserts maps how easily New Yorkers can reach a usable restroom along real walking routes. It measures access; FLUSHING asks where the next restroom should go. The two can be read together.

One file, works offline

The whole tool is a single HTML file with every district inside. It opens in any browser with no login, install or internet connection. The restroom list can be refreshed from NYC Open Data under Settings; other data is updated when the tool is rebuilt.
